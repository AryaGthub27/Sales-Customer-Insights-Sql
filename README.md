# Sales and Customer Insights using SQL

## Project Overview
This project analyzes sales performance and customer purchasing behavior using SQL. The dataset contains customer, product, and order information across multiple regions.

## Objectives
- Identify top-selling products
- Analyze revenue trends
- Find high-value customers
- Automate reporting using views and stored procedures

## Tools Used
- SQL
- MySQL

## SQL Concepts Used
- Joins
- Common Table Expressions (CTEs)
- Window Functions
- Aggregations
- Views
- Stored Procedures

## Key Insights
- Identified top-performing products by revenue
- Analyzed monthly sales trends
- Segmented customers based on spending
